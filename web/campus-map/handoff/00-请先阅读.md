# NKUStudy 校园地图完整交付包

版本：2026-10-16，包含用户已确认的最新界面、地点标签、模糊搜索和图层／全校视图易用性调整。此包为本地交付，不代表已经部署、配置微信业务域名或通过真机验收。

## 先做这三件事

1. 把整个压缩包解压到一个新文件夹，不覆盖原网站或小程序。
2. 安装 Node.js（建议 22.12 或更新的 22.x 版本），在解压目录运行 `node verify-delivery.mjs`，检查文件完整性。
3. 阅读 [完整接入说明](01-完整接入说明.md)。只看效果可直接使用 `web-dist/`；需要修改则进入 `campus-map/` 安装依赖。

## 文件分别用来做什么

| 目录／文件 | 用途 |
| --- | --- |
| `campus-map/` | 完整网页源码、生成式模型代码、原始轮廓、资源、锁文件和测试；不含 node_modules |
| `web-dist/` | 当前版本已经构建好的网页，上传此目录**里面的内容**到 `/campus-map/` 对应的独立服务器目录 |
| `models/model-catalog.json` | 当前 93 个建筑／地标的结构化数据快照，含坐标、轮廓及复合体量；不能代替精细模型代码 |
| `models/place-catalog.json` | 110 个地点条目、其中 78 个默认命名标签及简称、分类、来源说明 |
| `models/模型与代码索引.md` | 每类建筑模型及景观对应哪些源码文件 |
| `wechat-demo/` | 可单独导入开发者工具的最小 JS 示例，也可摘取地图页合并到现有小程序；需填自己的 AppID 和 HTTPS 域名 |
| `deployment/` | 待管理员审核的 Nginx 配置片段，不会自动修改服务器 |
| `previews/` | 当前真实页面截图，供交接对照；不是运行时模型或地图瓦片 |
| `verification/` | 交付检查记录，明确哪些已验证、哪些还需真机／管理员验收 |
| `SHA256SUMS.json`、`verify-delivery.mjs` | 解压后的文件校验与示例逻辑检查 |

## 最快本地打开方式

在解压目录打开 PowerShell：

```powershell
cd .\campus-map
npm ci
npm run check
npm run preview -- --host 0.0.0.0 --port 4180
```

电脑打开 `http://127.0.0.1:4180/campus-map/?embed=wechat`。手机与电脑连接同一个可信 Wi-Fi，打开预览终端输出的 **Network 地址**，末尾加 `/campus-map/?embed=wechat`（如果输出已经含路径，不要重复添加）。手机不能用电脑的 `127.0.0.1`。仅在可信私人网络放行本地预览，测试结束按 Ctrl+C。

包内预置的 `campus-map/dist/` 与 `web-dist/` 一致，所以装完依赖可直接 preview；修改后重新运行 build/check。

## 必须知道

- 这里的建筑是 Three.js 代码和轮廓数据生成的模型，不是 Blender／GLB／FBX 文件；完整建模代码已随包提供。没有虚构“可导入 Blender 的精细模型”。
- 本地图自身不需要资料库、Supabase、业务接口、API 密钥或外部地图 SDK；首次安装依赖仍需要 npm 网络。
- 真实网页、模型、搜索、树位、配色及桌面布局均保留；没有将截图替换成地图。
- 部分地点为用户参考截图估位，未命名建筑不编造名称；不用于精确导航。原始参考材料及校徽使用权、地图公开展示要求须由发布方审核。
- 收藏和最近只保存在当前浏览器／微信网页环境本机，不跨设备同步。
- 不包含原站资料库、后台、数据库配置、开发者私人配置、真实 AppID、证书、node_modules 或旧版本压缩包。微信示例默认域名是已有项目的 `https://nkulawer.cn`，并不保证该域名已部署当前地图。
