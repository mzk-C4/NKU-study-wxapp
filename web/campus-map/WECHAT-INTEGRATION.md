## 检查与限制

`npm run check` 包含类型/构建、原有几何测试和新增离线接入测试。`scripts/browser-integration-smoke.mjs` 需专用本地 Chrome 调试端口9229和本地服务，可检查手机模拟布局、3D搜索/复位、实际上下文丢失、完整2D、双指缩放、无WebGL降级、非法链接和桌面布局。不是微信真实设备测试。

小程序分享依赖微信提供 `webViewUrl`。若该字段缺失，会退回入口建筑；这不是保证任何客户端都实时分享最新选择。正式发布前必须用真实微信测试。
