## 当前状态

- 已实现：纯 Three.js 的可交互白模场景、建筑/道路/绿地/水面分层、建筑搜索与选中定位、分区聚焦、触摸平移缩放与旋转按钮、北上东右的默认视图与动态指南针、WebGL 不可用时完整2D降级、模型远近自动分级与按需绘制、性能面板、数据校验。
- 已导入：通过校区 OSM 边界筛得 82 个建筑体块、234 条道路、100 个绿地/水面与 9 个公共节点。`src/data/jinnan-model.ts` 由脚本生成；`data/` 保留原始审核数据和模型清单，但不会被 Vite 自动发布。
- 待核验：OSM 是开放的候选几何来源，不是校方现状保证。公开前仍须逐一核实名称、用途、楼高、入口、在建区域与使用许可。

## 数据、许可与发布红线

- `OpenStreetMap` 数据在其 ODbL 条款下可用，最终使用时须显示署名并履行相应衍生数据库义务：<https://www.openstreetmap.org/copyright>。
- 不得把 Apple/高德/百度等地图截图或模型描线后作为本项目数据；本项目只借鉴“简化白模、清晰分层”的抽象风格。
- 未取得当期资料和相应确认前，不把试验白模接入公开网站，也不将路线标为精确导航。公开地图还需评估地图审核与相关合规要求。

## 坐标与方向

- 数据转换时统一采用 `X 向东、Z 向南`；默认相机从南侧俯视，因此屏幕为“北上、东右”，可直接和常规卫星图对照。
- 可自由旋转场景；右上角指南针箭头始终投影显示真实北向。点击右侧 `N` 或左侧“回到全校视图”可恢复北上视角。

## 手机交互与性能更新（2026-10-15）

默认远近自动分级；通过“模型精度 → 完整精细”或 `?detail=full` 保留原完整模型浏览。电脑侧栏与鼠标旋转不变。手机单指平移、双指捏合缩放/扭转转向/上下滑动俯仰；指南针只恢复北向。默认清晰抗锯齿，菜单可切换省电。详见 [最新手势、抗锯齿与备份说明](docs/手机手势与抗锯齿更新.md) 和 [模型分级说明](docs/手机交互与模型分级说明.md)。
