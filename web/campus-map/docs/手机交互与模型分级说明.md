## 手势与镜头

手机单指拖动平移，双指横向同向拖动平移，双指张开/合拢缩放、扭转转向；双指平行上下滑动调整俯仰。多指操作、拖动与取消触摸不会误点建筑。

手机主要通过双指扭转转向；“俯”按钮仍可快速切换俯视/斜视。点击指南针/N只恢复北向，菜单“回到全校视图”才会完整复位。电脑版保留鼠标旋转操作。

平移沿水平地面，不再改变目标高度；每次控制器变化和阻尼更新均检查镜头。镜头不低于地面上方3米，俯仰角约11°–83°（从正上方向计算）；目标点限于校园边界外100米以内。此约束防止进入底盘下方，不是完整的建筑碰撞系统。

点击仅选择，不跳转镜头；搜索会聚焦建筑。随后缩放围绕当前视角中心，不会重新跳回已经离开的建筑。手机聚焦考虑画面宽度；雕像聚焦距离增加，防止被顶部工具栏遮挡。

设计参考：[Mapbox 手势](https://docs.mapbox.com/mapbox-gl-js/guides/user-interactions/gestures/)、[Three.js 控制器](https://threejs.org/docs/pages/OrbitControls.html)。这里是按校园地图需求调整，不是完全照搬其默认手势。

## 模型精度与性能

精細地标以屏幕投影大小选择远/中/近档，并有约12%切换缓冲，避免缩放边缘闪烁。近档显示原模型；中/远档保留原模型中较大的连续实体，并按材质合批，不使用整个建筑包围盒代替楼体，所以不填死原有庭院。普通白模本来已低面数，保持原样。雕像按小型地标处理，保留人物轮廓。

松树按每棵树的相机距离分档，用实例化批次显示，保留1704棵树的位置、大小、树干粗细和颜色；远处用单层低面数树冠，近处恢复原有三层树冠。完整精细模式也恢复全部原树模型。

镜头、图层、精度、选择与图片资源改变时重绘；镜头阻尼结束后静止停绘。后台继续暂停渲染，WebGL2失败仍进入完整2D地图。

当前仍会在初始化时生成原精细模型与两个低精度档，主要改善绘制和交互开销；不是按需下载，也不保证降低首屏加载时间或内存峰值。手机首屏/内存/温升需真机测量，后续可再拆分模型资源和按区域加载。

## 验证与体验

`npm run check` 包含几何/树位置/原建筑、微信接入与镜头/LOD离线回归。

`scripts/controls-lod-browser-smoke.mjs` 检查生产构建手机模拟：单指平移、双指平移、捏合、不误选、地面/校园边界、选中后平移缩放不跳回、近远精度、静止停绘、图层重绘、完整精细电脑版、2D控件。`scripts/browser-integration-smoke.mjs` 回归搜索、分享参数、实际WebGL上下文丢失与2D降级。

真实手机：电脑手机同一可信Wi-Fi，在项目目录运行 `npx vite preview --host 0.0.0.0 --port 4180`；在手机打开终端打印的 Network 地址并追加 `?embed=wechat`。不要使用手机上的 `127.0.0.1`。防火墙只允许专用网络，结束按Ctrl+C。更新后重启预览并刷新；仍显示旧版时清理该网页缓存。

微信真实设备、不同GPU、弱网、首屏时间和持续交互发热仍待验收。
