# 手机手势与抗锯齿更新

日期：2026-10-15。仅本地实现与验证，未部署服务器或上传微信小程序。

方向修订（2026-10-15）：根据用户体验反馈，将双指转向相对首版反向；仅改变相机方位角的手势符号，不改变捏合、平移、俯仰、指南针和鼠标。新增正反两个方向及旋转+缩放组合的带符号回归断言。本次修订前源文件保存在 `D:\自制网站\backups\campus-map-lab-20261015-before-rotation-direction`。

## 新操作方式

- 单指拖动：平移地图。
- 双指捏合：以双指中点为锚缩放。
- 双指扭转：连续转向，可与捏合和横向平移组合。
- 双指大致横向分开、同时向上/下滑动：调整俯仰，不再把这类手势解释为平移。
- 双指水平同向拖动：平移；斜向混合手势按意图归类。
- 指南针或N按钮：只恢复朝北，保留当前位置、缩放和选中建筑。菜单里的“回到全校视图”才会完整复位。

双指手势先经过小幅意图判断，锁定为俯仰或缩放/转向，避免颤动时意外倾斜。两根手指在同一帧内合并处理，避免事件先后顺序造成误判。抬起一根后会重新设定平移基准；取消、第三根手指、页面离开不误选模型。鼠标仍由原控制器处理，原网页版侧栏和精细模型保留。

交互参考：[Mapbox 官方手机手势](https://docs.mapbox.com/mapbox-gl-js/guides/user-interactions/gestures/)。当前并非完整导航产品：不提供定位或道路导航。

## 画面改进

原手机版关闭硬件抗锯齿，并把渲染密度限制为1.25。现在默认“清晰抗锯齿”：

1. 渲染密度上限提升到2，受屏幕实际密度和300万像素预算共同限制。
2. 场景目标启用最多4倍MSAA，设备不支持时按能力降低；用于平滑楼体、屋顶和道路的几何边缘。
3. 色彩输出之后增加FXAA边缘处理，减轻小窗框和细线的阶梯感。搜索栏、建筑文字等HTML界面不经过该滤镜。
4. 场景目标才使用多重采样/深度，后处理目标不额外分配这些缓冲，控制显存消耗。
5. 保持建筑/树木远中近分级、静止停绘和后台暂停，不持续提高绘制频率。统计面板同步本次实际绘制，不再残留上一视角的数字。

菜单“图层 / 分区”内新增画面质量选项。“省电”使用最高1.25倍密度、最多2倍MSAA，仍保留边缘处理。画质越高，像素和采样开销越大；低端机建议使用省电，不保证所有设备维持相同帧率。

后处理出错会退回原生抗锯齿的3D渲染；WebGL2初始化失败或上下文丢失仍使用完整2D地图。多边形本身的硬朗造型（如雕像、松树）没有改成圆润曲面；这次主要处理画面边缘，不是重建几何。

实现依据：[Three.js 多重采样目标](https://threejs.org/docs/pages/RenderTarget.html)、[官方 FXAA 示例](https://threejs.org/examples/webgl_postprocessing_fxaa.html)，并以项目内安装版本的源码核对色彩处理顺序。

## 验证与限制

- `npm run check`：构建、93个建筑/地标、树位置、精细模型、分享链接、2D和镜头/分级回归；新增角度跨±180°处理、双指中点与像素预算策略测试。
- `scripts/touch-aa-browser-smoke.mjs`：390×844、设备密度3的手机模拟。验证连续扭转、捏合、组合手势、俯仰、平移、抬指过渡、取消、指南针保留视角、清晰/省电切换、静止停绘及后处理失败回退。
- 同一图书馆近景和全校远景分别保存旧/新版截图，确认几何边缘改善。此模拟中清晰画布为780×1688，MSAA4、FXAA开启；省电为487×1055，MSAA2。
- 原有浏览器集成测试覆盖搜索、上下文丢失、无WebGL2、完整2D、非法链接与桌面布局。
- 真实微信/iOS/Android GPU、持续交互帧率、温升和弱网仍待真机验收。抗锯齿减轻阶梯和细线闪烁，不承诺完全消除所有亚像素细节的时间性闪烁。
