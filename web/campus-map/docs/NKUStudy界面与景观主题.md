## 已实现

- 手机版：NKUStudy 页头、校区切换样式、2D/3D分段选择、搜索、全部/教学/食堂/宿舍分类、紫色地图标记、指南针、缩放及图层设置。
- 底部地点卡：全部/常用/最近列表、建筑详情、收藏、关闭详情和展开列表。93个建筑/地标均可搜索；图中名称可简化显示，原始建筑名称和ID不变。
- 收藏与最近仅保存在本机；最近最多12项。存储不可用时本次页面仍可使用，但不承诺跨页面保存。
- 分类只筛选地点列表和标记，不删除或改动地图上的建筑。
- 八里台没有这套模型数据，所以明确禁用该校区入口，不生成假校区。当前可用的是津南。
- 电脑版保留独立侧栏和鼠标控制；模型精度、清晰/省电画质、完整精细模式、分享链接、手机手势及2D降级继续可用。
- 默认不展示FPS/绘制次数等开发信息；需要时使用 `?debug=1`。

## 配色与景观

| 用途 | 颜色 |
| --- | --- |
| 按钮、标记、选中轮廓 | `#57216F` |
| 浅紫界面背景 | `#F5F1F8` |
| 地图底色 | `#F4F0E7` |
| 绿地 | `#B8D0A0` |
| 水体 | `#ADCBD6` |
| 道路 / 边线 | `#EEE9E1` / `#C5BBAA` |

树冠改为柔和水滴形/椭圆形的园林样式，最高约9.64米、最大冠幅6.4米；保留原来1.12米的树干底部直径。使用少量稳定的鼠尾草绿色差异，按树位确定，不随帧随机变化。

保留原有规则排布、22米间距、建筑避让、运动场避让、东北湖区留空和指定无树路段。实际3D树位与修改前备份逐点一致：东侧630处，西侧1068处。2D复用同一套1698个点，按毫米精度保存于 `src/data/landscape-tree-sites.ts`，没有另撒一批树。离线几何测试不传精细建筑外伸包围盒时得到的候选数可能更多，不应当作实际页面种植数。

2D的新增浅绿种植底色限于原东部种植范围，并排除东北湖区和建筑包络；道路、水面、建筑仍由原数据覆盖。水体与原绿地的几何边界没有改变。树仍使用实例化和远/中/近分级，远景保留低面数档。

2026-10-16 按用户提供的界面参考，将绿地从偏灰的 `#D4DFCD` 调整为浅草绿 `#B8D0A0`。2D、3D原有绿地及东部种植地块同步调整；仅改底色，不改边界、树位、树形、水体或建筑模型。调整前相关文件保存在 `D:\自制网站\backups\campus-map-green-20261016`。

## 建筑保持不变的验证

- 17个受保护文件逐一校验，包括原始建筑数据、补绘数据、精细建筑模块、雕像、体育场、白模挤出、分级管理及相机/手势/抗锯齿代码。
- 对主程序中27处建模函数、建筑材质定义和建筑组装代码单独做哈希对照。
- 形状、位置、高度、尺寸、楼翼、庭院、外立面、原建筑材质和精细结构均保持原样；紫色选中轮廓与地图标记属于界面覆盖层。
- 校验基线为 `reference/building-model-preservation.json`，随项目携带；常规检查不依赖外部备份目录。不得为了绕过检查擅自更新基线。
- 当前整套地图仍是待核验试验模型，不提供真实导航或定位服务。
