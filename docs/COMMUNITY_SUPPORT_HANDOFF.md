## 现有客户端

- 首页轮播下方的独立海棠徽标统计卡显示花/币图标与数值，明确标注“全社区累计”；第5张校园海棠花币轮播可查看规则，两处构图区分。协作者下方仍保留计数和等级说明。每个账号自己的「我的」页显示个人累计、等级和两条升级进度，无公开个人主页。
- 下载 HTTP 200 且有本地路径后异步上报，不阻塞阅读。只复制链接、失败、超限转浏览器不计；同一成功回调不重复上报。课程ID缺失时从课程资源列表上下文补齐。
- 学校指南/学院变体的公开来源使用 guide_source；内置学生 PDF 通过打开选项显式禁用上报，仍可正常下载阅读，不能把本地PDF条目ID当成后台来源ID。
- 下载开始捕获会话；切到另一个有效账号时仅计公共量，游客后登录不补个人。原账号失效/退出后停止该次上报，401不自动转游客重发。
- 成功回执必须匹配event_id，公共计数只读返回快照，绝不在本机＋1。统计服务关闭/503时清除旧数字、个人卡片；迟到旧revision和关闭前未完成的记账响应不能恢复旧统计。
- 评价提交只感谢投稿，提示审核通过公开后计币；不读取旧提案的可选提交记币回执，不发送客户端加币请求。返回首页重读能力/公共数，进入「我的」重读本人统计。
- 感谢弹窗可关闭或本次使用不再提醒，捐助说明仅进入既有网站入口；花币免费、不兑换、不提现，与支付分离。

## 正式契约要点

基址 `https://nkustudy.top/api/v1`，成功为 `{code:0,data:...}`。完整客户端字段摘要在 [API.md](./API.md)。

1. `GET /home` 的 community_support 包含 version=1、enabled、持久revision、flowers、coins、review_rule=approved、download_reporting、personal_stats；数字为非负安全整数。能力缺失/关闭时显示“—”；真实0正常显示0。
2. `POST /community-support/downloads`，JSON≤4096字节，无查询。字段只允许event_id、kind、resource_id、course_id、attribution。事件ID16～96位 `[A-Za-z0-9_-]`；资源/课程ID≤200字。resource必须匹配课程；guide_source必须属于公开指南/学院变体且ID无歧义，课程ID空。
3. account要求Bearer；community禁止Authorization。成功返回匹配事件ID、recorded=true和完整公共统计。相同事件/正文/归属重放不再计数；冲突409。客户端6000ms超时，没有持久化自动重试队列；超时可能已落账，不新造ID重发。
4. 错误为400 INVALID_SUPPORT_EVENT、401 AUTH_REQUIRED、404 RESOURCE_NOT_FOUND、409 EVENT_CONFLICT、429 RATE_LIMITED、503 SUPPORT_UNAVAILABLE。账号总量30次/分钟、200次/天，同账号同资源5次/分钟、50次/天；匿名来源总量10次/分钟、60次/天，同来源同资源3次/分钟、20次/天。实际以后台限制为准。
5. `GET /me/community-support`，必须Bearer，无参数，返回本人 `{flowers,coins}`，无level。等级 `1 + floor(min(flowers,coins)/10)`：0/0→Lv.1；10/9→Lv.1；10/10→Lv.2；25/12→Lv.2还差8币；30/30→Lv.4。换设备按同账号查询，无永久本地贡献缓存。
6. 公共鲜花以991条资料沉淀为固定基数加成功下载事件；公共硬币按迁移纳入的历史及新增评价有效公开状态计算，待审/隐藏/撤回不计，恢复可恢复，重复批准不重复计。历史贡献不补个人，个人等级公式不变。
7. 后台采用评价JSON与SQLite统计的可恢复一致性，非原生跨存储事务；异常时关闭统计能力。注销清除个人归属和统计，保留公共有效总量，不能重新绑定已清理的事件。
8. 客户端完成事件可伪造，幂等与限流不证明真实阅读；花币不用于现金或可兑换奖励。数据库、部署、备份及注销账本由现有网站维护方负责。
