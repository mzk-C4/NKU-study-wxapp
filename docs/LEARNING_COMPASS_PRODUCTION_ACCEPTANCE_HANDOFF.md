# 学习指南针最终生产验收交接

日期：2026-08-25

## 结论

普通指南生产链路已经具备上线条件；客户端正式AI接线已经完成。当前不能宣称全部发布完成，剩余事项需要生产后台、微信公众平台、真实微信登录或发布权限。

## 已完成并有证据

- 生产指南18篇，五分类数量3/3/4/5/3。
- 转专业29个学院variant按需加载；抽查正文互不相同。
- search-index含18个顶层指南，转专业只出现一次。
- R2抽查PDF和DOCX均返回200，Content-Type分别正确。
- AI无Token请求返回401 `AUTH_REQUIRED`。
- 客户端production AI使用统一Bearer Token、30秒超时、数字入学年份、最多9轮history。
- 客户端已移除指南入口、AI页面、发送、新话题、编辑重问和重新生成的production建设中门禁。
- 普通指南和AI引用复用R2来源打开器；生产只接受`resources.nkustudy.top/guide-sources/`。
