## 功能与安全验收

- [ ] 游客可浏览首页、课程、资料、评价与指南
- [ ] 收藏、投稿、写评价和失效报告时才触发微信登录
- [ ] A–E 分类、课程属性、标签和建议修读阶段互不混用
- [ ] 搜索课程名、简称、教师与标签均能召回；搜索“化学”至少返回有机化学和环境化学
- [ ] 资料列表不暴露分享链接，详情页可复制链接和提取码
- [ ] 评价绑定课程、教师、学年学期，少于 3 条不显示综合分
- [ ] 投稿与评价默认待审核，管理端通过后才公开
- [ ] 页面覆盖加载、空数据、网络错误和未登录状态
- [ ] 375px 小屏、刘海屏、底部安全区和微信大字体显示正常
- [ ] 仓库历史不存在密码、Token、OpenID 或网盘管理凭证

## 断网验收方法

不要使用微信开发者工具调试器 Network 面板的全局 `Offline` 作为业务断网证据。该选项会同时阻断开发者工具自己的 `127.0.0.1` 运行时和按需组件加载；切换尚未实例化的页面时可能出现 `Component is not found in path "wx://not-found"`、内部 `__dev__` 资源 `ERR_INTERNET_DISCONNECTED` 以及整页空白。此时页面 JS/WXML 未获得运行机会，不能据此判断业务错误态是否有效。

正确的断网验收必须保持调试器 Network 为 `Online`，再选择以下一种方式只让业务 API 失败：

1. 保持开发者工具运行，断开电脑的外部网络连接；不要关闭或阻断 localhost。
2. 使用请求阻断功能，只阻断 `https://nkustudy.top/api/v1/*`，不要阻断 `127.0.0.1`、`localhost` 或开发者工具 `__dev__` 资源。
3. develop 环境显式切换 `reference` profile，并在本地参考服务未运行时重新编译；验收结束后移除 `nkustudy_api_profile` 并重新编译，恢复 production。

验收前先清空 Console。若出现 `wx://not-found` 或内部 localhost 加载失败，本次证据无效，应恢复 Network 为 `Online` 并普通编译，等待运行实例恢复后重新测试。

预期结果：

- 首页、课程列表、课程概览和指南在业务 GET 失败后显示安全错误与“重新加载”；
- 恢复网络后重试可重新请求；
- 合法空响应显示空态，不冒充网络错误；
- “我的”不依赖公开 API，断开外部网络后仍显示本机静态内容和浏览历史；
- 未实际在真机或体验版运行时，继续记为 `SKIP`，不能由开发者工具结果推断。

## 学习指南针首页视觉验收

批准参考图：`图片和附件/learning-compass-home-approved-20260823.png`。

1. 操作：在微信开发者工具普通编译后打开“指南”Tab。
   预期：导航标题为“学习指南针”；页面出现品牌标识、模块说明、学生共建提示、搜索入口、AI入口、五个一级分类和“近期更新”区域。
2. 操作：在375px左右小屏和常见iPhone尺寸查看首屏。
   预期：五个分类保持一行且文字不截断；搜索框、AI卡片和列表不横向溢出；底部TabBar不遮挡内容。
3. 操作：开启微信大字体后重新进入页面。
   预期：标题、分类、指南标题和适用范围仍可读，主要按钮仍可点击，不发生重叠。
4. 操作：点击顶部普通搜索或“查看全部”。
   预期：进入现有搜索页；返回后指南页已有加载状态保持。
5. 操作：依次点击五个一级分类。
   预期：选中态立即可见，并进入带相应关键词的普通搜索；不请求未开放的五分类生产接口。
6. 操作：点击“开始提问”。
   预期：显示“AI问答正在建设中”，不进入虚构页面、不请求未开放AI端点。
7. 操作：生产API返回空指南列表。
   预期：显示真实空态和普通搜索提示，不展示批准图中的示例文章冒充生产内容。
8. 操作：有真实或reference指南数据时点击任一指南。
   预期：列表行全宽、按压有反馈，并按稳定ID进入现有指南详情页。
9. 内容检查：若首条文章使用2026—2027第一学期选课通知。
   预期：更新时间必须为 `2026-08-17`，不得沿用批准视觉图中误写的 `2025-08-17`。

当前自动打开开发者工具结果：`BLOCKED`。项目脚本未在常见安装目录找到微信开发者工具；本地自动化通过不能替代上述视觉验收。

## 学习指南针 AI 已回答与断网恢复页验收

批准参考图：

- 已回答状态：`图片和附件/learning-compass-ai-answer-approved-20260823.png`；
- 断网恢复状态：`图片和附件/learning-compass-ai-network-offline-approved-20260823.png`。

### 已回答状态开发者工具预览

1. 操作：在微信开发者工具的 `develop` 环境保持正常联网，清除缓存并编译，打开“指南”并点击“开始提问”。
   预期：进入“学习指南针 AI 问答”，自动带入成绩复核问题，并按批准图展示问题气泡、回答正文、两处`[来源1]`、官方提醒、来源卡片、回答操作和底部继续追问输入框。
2. 操作：检查页面顶部。
   预期：标题下方同时显示带列表图标的“对话记录”和带加号圆形图标的“新开话题”；触控区域清楚，不与系统胶囊或返回键重叠。
3. 操作：点击“对话记录”。
   预期：从屏幕左侧展开会话抽屉，不再从底部显示系统菜单；顶部有“搜索对话内容...”搜索框，列表按“置顶、今天、昨天、7天内、30天内”分组且组内按更新时间倒序排列，底部不显示头像或个人资料。
4. 操作：点击任意记录右侧图钉，再长按另一条记录。
   预期：右侧显示图钉而不是星标/收藏；点击图钉可置顶或取消置顶。长按弹出“置顶/取消置顶”和“删除会话”，删除前必须再次确认；删除当前会话后进入新话题，删除其他会话不影响当前内容。
5. 操作：在底部输入框连续输入多个汉字，再检查附件按钮。
   预期：输入第一个字后光标继续保留，可以连续输入；只有真实失焦、发送或切换会话时才结束输入焦点。附件图标显示为竖向双层回形针，不变形成单层U形或异常方框。
6. 操作：搜索任意记录标题并点击结果。
   预期：搜索实时缩小列表；点击记录恢复其已回答或断网状态并关闭抽屉，全程不发AI请求。点击遮罩或抽屉顶部关闭按钮可以关闭抽屉。
7. 操作：点击“新开话题”。
   预期：清空当前问题和回答、聚焦底部输入框，但旧问题仍保留在对话记录中；再次打开对话记录可以恢复。会话按每条记录更新时间保存30天，超过30天的记录不再展示。
8. 操作：点击回答下方的复制、重新生成、赞和踩。
   预期：复制得到批准回答文本；重新生成诚实提示“AI问答正在建设中”；赞/踩只保存在本机当前页面状态，不调用未开放接口。
9. 操作：点击“查看原文”。
   预期：提示“原文跳转正在建设中”，不复制链接、不打开伪造页面；该按钮保留为资料库与来源路由完成后的原文定位入口。
10. 操作：检查底部输入区和说明。
   预期：占位文案为“继续追问这个问题”，显示“当前第1/10轮”和“会话记录保存30天 · 单个话题最多10轮”；输入区不遮挡来源或回答操作。
11. 操作：检查 Network。
   预期：`preview=answer`只在`develop`本地展示批准视觉，不请求`/guide-assistant/answers`或其他AI接口，不代表AI服务上线。

### 断网状态开发者工具预览

1. 操作：在开发者工具 Console 执行：
   `wx.navigateTo({url:'/pages/guide-assistant/index?preview=network-error&question='+encodeURIComponent('我对一门课程的成绩有异议，应该怎么申请复核？')})`
   预期：联网电脑也能进入批准的断网视觉预览；顶部同样显示“对话记录”和“新开话题”。
2. 操作：检查问题、恢复卡和输入框。
   预期：显示问题气泡、紫色检查网络按钮、复制/就地编辑、“请检查网络或重试”、“浏览知识库”“去普通搜索”和固定底部输入；不显示伪造回答或来源。
3. 操作：点击“新开话题”，再点击“对话记录”。
   预期：断网状态下清空当前问题但保留本机历史；可从记录中恢复原问题，且仍保持断网恢复状态。

### 真实断网行为

1. 操作：保持开发者工具 Network 面板为`Online`，只断开电脑外部网络；直接进入AI问答页后输入问题并发送。不要使用调试器全局`Offline`，否则可能破坏开发者工具运行时。
   预期：进入真实断网恢复状态，不展示批准回答预览。
2. 操作：检查“浏览知识库”和“去普通搜索”。
   预期：前者切回指南Tab，后者进入普通搜索并携带当前问题；均不调用AI接口。
3. 操作：先在底部保留草稿，再点击问题编辑按钮，分别验证取消、发送和空白拦截。
   预期：问题在原气泡位置就地编辑，底部草稿不变；取消恢复原问题，发送更新问题，空白不可发送。
4. 操作：保持断网点击重试，再恢复外部网络后重试。
   预期：断网时保持安全提示且不无限重试；联网后只提示网络恢复，不伪造AI回答。
5. 操作：点击附件图标。
   预期：提示“暂不支持附件”，不选择或上传文件。
6. Network检查：完成以上流程。
   预期：没有AI端点请求；trial/release在线点击仍诚实提示“AI问答正在建设中”，断网才进入真实恢复页。

自动化只能验证结构、状态、存储和导航，不能证明与批准图像素级一致。微信开发者工具、375px小屏、微信大字体、真机和体验版仍需分别记录`PASS/FAIL/SKIP/BLOCKED`。
