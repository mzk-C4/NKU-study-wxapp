## 功能与安全验收

- [ ] 游客可浏览首页、课程、资料、评价与指南
- [ ] 收藏、投稿、写评价和失效报告时才触发微信登录
- [ ] A–E 分类、课程属性、标签和建议修读阶段互不混用
- [ ] 搜索课程名、简称、教师与标签均能召回；搜索“化学”至少返回有机化学和环境化学
- [ ] 资料列表不暴露分享链接，详情页可复制链接和提取码
- [ ] 评价绑定课程、教师、学年学期，少于 3 条不显示综合分
- [ ] 投稿与评价默认待审核，管理端通过后才公开
- [ ] 页面覆盖加载、空数据、网络错误和未登录状态
- [ ] 375px 小屏、刘海屏、底部安全区和微信大字体显示正常
- [ ] 仓库历史不存在密码、Token、OpenID 或网盘管理凭证

## 断网验收方法

不要使用微信开发者工具调试器 Network 面板的全局 `Offline` 作为业务断网证据。该选项会同时阻断开发者工具自己的 `127.0.0.1` 运行时和按需组件加载；切换尚未实例化的页面时可能出现 `Component is not found in path "wx://not-found"`、内部 `__dev__` 资源 `ERR_INTERNET_DISCONNECTED` 以及整页空白。此时页面 JS/WXML 未获得运行机会，不能据此判断业务错误态是否有效。

正确的断网验收必须保持调试器 Network 为 `Online`，再选择以下一种方式只让业务 API 失败：

1. 保持开发者工具运行，断开电脑的外部网络连接；不要关闭或阻断 localhost。
2. 使用请求阻断功能，只阻断 `https://nkustudy.top/api/v1/*`，不要阻断 `127.0.0.1`、`localhost` 或开发者工具 `__dev__` 资源。
3. develop 环境显式切换 `reference` profile，并在本地参考服务未运行时重新编译；验收结束后移除 `nkustudy_api_profile` 并重新编译，恢复 production。

验收前先清空 Console。若出现 `wx://not-found` 或内部 localhost 加载失败，本次证据无效，应恢复 Network 为 `Online` 并普通编译，等待运行实例恢复后重新测试。

预期结果：

- 首页、课程列表、课程概览和指南在业务 GET 失败后显示安全错误与“重新加载”；
- 恢复网络后重试可重新请求；
- 合法空响应显示空态，不冒充网络错误；
- “我的”不依赖公开 API，断开外部网络后仍显示本机静态内容和浏览历史；
- 未实际在真机或体验版运行时，继续记为 `SKIP`，不能由开发者工具结果推断。

## 学习指南针首页视觉验收

批准参考图：`图片和附件/learning-compass-home-approved-20260823.png`。

1. 操作：在微信开发者工具普通编译后打开“指南”Tab。
   预期：导航标题为“学习指南针”；页面出现品牌标识、模块说明、学生共建提示、搜索入口、AI入口、五个一级分类和“近期更新”区域。
2. 操作：在375px左右小屏和常见iPhone尺寸查看首屏。
   预期：五个分类保持一行且文字不截断；搜索框、AI卡片和列表不横向溢出；底部TabBar不遮挡内容。
3. 操作：开启微信大字体后重新进入页面。
   预期：标题、分类、指南标题和适用范围仍可读，主要按钮仍可点击，不发生重叠。
4. 操作：点击顶部普通搜索或“查看全部”。
   预期：进入现有搜索页；返回后指南页已有加载状态保持。
5. 操作：依次点击五个一级分类。
   预期：选中态立即可见，并进入带相应关键词的普通搜索；不请求未开放的五分类生产接口。
6. 操作：点击“开始提问”。
   预期：显示“AI问答正在建设中”，不进入虚构页面、不请求未开放AI端点。
7. 操作：生产API返回空指南列表。
   预期：显示真实空态和普通搜索提示，不展示批准图中的示例文章冒充生产内容。
8. 操作：有真实或reference指南数据时点击任一指南。
   预期：列表行全宽、按压有反馈，并按稳定ID进入现有指南详情页。
9. 内容检查：若首条文章使用2026—2027第一学期选课通知。
   预期：更新时间必须为 `2026-08-17`，不得沿用批准视觉图中误写的 `2025-08-17`。

当前自动打开开发者工具结果：`BLOCKED`。项目脚本未在常见安装目录找到微信开发者工具；本地自动化通过不能替代上述视觉验收。
