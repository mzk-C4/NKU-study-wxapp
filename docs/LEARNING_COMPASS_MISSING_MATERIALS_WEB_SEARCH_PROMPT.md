## 五、停止和判断规则

1. 同一材料找到官方完整来源后，停止重复搜索转载版本。
2. 标题相同但文号、年份或适用范围不同的文件必须分别列出，不能混合。
3. 没找到不等于不存在；只能写“截至2026-08-23，在已检索的公开官方来源中未找到”。
4. 新版文件若没有明确废止条款，不自行宣布旧版失效。
5. 学院文件不能扩大为全校规则，往年通知不能冒充当前学期安排。
6. 如果官方页面给出附件但附件打不开，分别记录页面已核验、附件受阻。
7. 不为追求完整而引用第三方转载或生成缺失正文。
