## 1. 结论与边界

`SYK-01` 至 `SYK-08` 保持原任务定义，不再按“只搜索课程”重新定义。本交接只描述完成这些原任务所需、但当前生产 API 尚未提供的能力。

本交接覆盖：

- `SYK-01`：课程、教师、资料、指南四类搜索结果；
- `SYK-02`：客户端使用 Fuse.js，并按课程名、简称、别名、教师名和标签设置权重；
- `SYK-03`：为生产数据上的“化学”完整召回提供可验证数据基础；
- `SYK-05`：指南列表、详情、相关课程和纠错入口；
- `SYK-07`：指南更新时间和内容分类边界；
- `SYK-08`：生产搜索索引和指南读取接口。

本交接明确不覆盖：

- `SYK-04` 已在客户端完成，不要求 API owner 重做筛选、高亮、空态、错误态和并发保护；
- `SYK-06` 的首批指南正文由邵游堃自行整理，不要求 API owner 编写内容；
- 不要求本地参考 `server/` 成为生产服务；
- 不要求开放生产凭据、管理接口、R2 内部路径或其他私有字段；
- 本文件不是部署授权，也不要求在未确认契约前直接修改生产状态。

## 2. 已核实的当前事实

最新正式 API 文档说明当前实现以生产路由、服务层和 DTO 为准。经逐项核对：

1. 当前课程搜索为 `GET /api/v1/courses?q=<keyword>`。
2. `q` 在课程名称、摘要、学期、类别、考核方式、标签和教师中进行包含匹配，但响应结果始终是课程。
3. 当前课程 DTO 没有 `short_name` 和 `aliases`。
4. 当前教师只作为课程中的姓名字符串或评价分组字段出现，没有独立教师搜索结果 DTO。
5. `GET /api/v1/courses/:courseUid/resources` 只能读取一门已知课程的资料，不能跨课程搜索资料。
6. `/api/v1/search-index` 和 `/api/v1/guides` 在当前版本明确未注册，调用返回 `404`。
7. 当前没有指南列表、指南详情、相关课程、更新时间、分类边界或纠错入口的正式公共契约。

因此，当前问题不是“已有接口文档写得不够详细”，而是原任务所需的部分生产能力尚未实现。仅向文档补写不存在的接口不能解除阻塞；需要先实现和验证，再更新正式 API 文档。

客户端当前保持安全降级：课程搜索可用；未开放的教师独立结果、全局资料搜索、指南搜索和指南页面不会伪造生产数据，也不会调用未注册端点。

## 3. 缺口与任务映射

| 缺口 | 当前生产能力 | 最小需要 | 阻塞任务 |
|---|---|---|---|
| 完整四类搜索索引 | 只有分页课程搜索 | 公开、完整、版本化的课程/教师/资料/指南索引 | `SYK-01/02/03/08` |
| 课程简称与别名 | 课程 DTO 无对应字段 | `short_name`、`aliases` 及其数据来源 | `SYK-02` |
| 独立教师结果 | 只有课程中的姓名字符串 | 稳定教师 ID、姓名、关联课程和去重规则 | `SYK-01` |
| 全局资料结果 | 只能按课程读取资料 | 可搜索的全部公开资料摘要及所属课程 | `SYK-01` |
| 指南列表和详情 | 接口未注册 | 列表、详情、分类、更新时间、相关课程 | `SYK-01/05/07/08` |
| 指南纠错入口 | 无正式契约 | 安全公开链接或受控提交方式 | `SYK-05` |
| 生产完整召回证据 | 只有本地 fixture 证据 | “化学”预期结果清单和只读联调证据 | `SYK-03/08` |

## 4. 最小生产契约

以下路径是与原任务和历史客户端最一致的推荐方案。若生产 owner 采用不同路径或返回组织形式可以调整，但能力、字段语义和验收条件不能缺失。

### 4.1 `GET /api/v1/search-index`

用途：一次读取经过公共字段白名单处理的完整搜索索引，由客户端 Fuse.js 在四类数据上执行匹配和权重排序。

该接口不应只是普通分页搜索接口。客户端若只拿到某一页数据，就无法证明全量召回，也无法在全局数据上正确使用 Fuse.js。若一次返回完整索引存在体积问题，生产 owner 需要提供等价的完整快照机制，例如可缓存静态索引，或带稳定快照版本的分片下载；普通的实时分页结果不能替代完整索引。

建议响应：

```json
{
  "code": 0,
  "data": {
    "version": "stable-index-version",
    "generated_at": "2026-08-16T12:00:00+08:00",
    "items": [],
    "total": 0
  }
}
```

每个索引项使用统一公共外形：

```json
{
  "id": "stable-public-id",
  "type": "course",
  "type_label": "课",
  "badge": "课",
  "name": "有机化学",
  "short_name": "有机",
  "aliases": ["有机化学基础"],
  "tags": ["化学", "实验"],
  "teachers": ["教师姓名"],
  "search_text": "经白名单构造的补充检索文本",
  "subtitle": "专业必修课 · 大二上"
}
```

公共字段约束：

- `id` 必须稳定，不能使用会随标题变化的临时数组下标；
- `type` 只允许 `course`、`teacher`、`resource`、`guide`；
- 缺失的字符串使用空字符串，缺失的数组使用空数组，不返回混合类型；
- `search_text` 必须由服务器按白名单构造，不能直接展开数据库、manifest 或管理记录；
- `version` 在索引内容变化时必须变化，`generated_at` 使用带时区的 ISO 8601；
- 索引必须只包含允许公开、已发布且未隐藏的内容。

#### 课程索引项

至少需要：

```json
{
  "id": "course-uuid",
  "type": "course",
  "name": "有机化学",
  "short_name": "有机",
  "aliases": ["有机化学基础"],
  "tags": ["化学", "实验"],
  "teachers": ["教师姓名"],
  "search_text": "课程摘要 学期 类别 考核方式",
  "subtitle": "专业必修课 · 大二上"
}
```

`short_name` 和 `aliases` 的权威来源、维护位置和空值语义需要写入正式文档。不能由客户端从课程名猜测或自行维护第二套别名。

#### 教师索引项

至少需要：

```json
{
  "id": "stable-teacher-id",
  "type": "teacher",
  "name": "教师姓名",
  "short_name": "",
  "aliases": [],
  "tags": [],
  "teachers": ["教师姓名"],
  "search_text": "教师姓名 相关课程名称",
  "subtitle": "相关课程 2 门",
  "related_course_ids": ["course-uuid"]
}
```

还需要明确：

- 教师数据的权威来源；当前课程教师来自已通过评价的分组，可能遗漏没有评价的任课教师；
- 同名教师如何区分，异体姓名如何合并；
- 教师稳定 ID 的生成与兼容规则；
- 最小交互按“教师结果展示相关课程”处理，不要求新增教师详情页。

#### 资料索引项

至少需要：

```json
{
  "id": "stable-resource-id",
  "type": "resource",
  "name": "2025年期末试题.pdf",
  "short_name": "",
  "aliases": [],
  "tags": ["往年真题", "化学"],
  "teachers": [],
  "search_text": "资料标题 描述 类型 所属课程",
  "subtitle": "有机化学 · 往年真题",
  "course_id": "course-uuid",
  "course_name": "有机化学",
  "resource_type": "往年真题",
  "term_label": "大二上"
}
```

最小交互按“资料结果跳转到所属课程的资料页”处理，因此只要提供稳定 `course_id`，本阶段不强制新增独立资源详情接口。如果产品要求资料结果直接打开独立详情，再另行补充 `GET /api/v1/resources/:resourceId` 契约。

#### 指南索引项

至少需要：

```json
{
  "id": "stable-guide-id",
  "type": "guide",
  "name": "退补选流程",
  "short_name": "",
  "aliases": [],
  "tags": ["退补选"],
  "teachers": [],
  "search_text": "指南标题 摘要 分类",
  "subtitle": "退补选 · 2026-08-16 更新",
  "category": "add-drop",
  "updated_at": "2026-08-16T12:00:00+08:00"
}
```

### 4.2 `GET /api/v1/guides`

用途：公开指南列表、分类切换和列表空态。

建议查询参数：

| 参数 | 语义 |
|---|---|
| `category` | 与服务器公开分类值精确匹配；空值表示全部 |
| `page` | 正整数，默认 `1` |
| `page_size` | 正整数，建议最大 `100` |

建议响应：

```json
{
  "code": 0,
  "data": {
    "items": [
      {
        "id": "stable-guide-id",
        "title": "退补选流程",
        "summary": "退补选时间与操作步骤",
        "category": "add-drop",
        "updated_at": "2026-08-16T12:00:00+08:00",
        "applicable_scope": "适用对象或空字符串",
        "related_course_ids": []
      }
    ],
    "total": 1,
    "page": 1,
    "page_size": 20,
    "facets": {
      "categories": ["course-selection", "training-program", "add-drop", "exam-grade"]
    }
  }
}
```

### 4.3 `GET /api/v1/guides/:guideId`

用途：指南详情、更新时间、相关课程和纠错入口。

建议响应：

```json
{
  "code": 0,
  "data": {
    "id": "stable-guide-id",
    "title": "退补选流程",
    "summary": "退补选时间与操作步骤",
    "category": "add-drop",
    "updated_at": "2026-08-16T12:00:00+08:00",
    "applicable_scope": "适用对象或空字符串",
    "steps": [
      { "title": "第一步", "body": "公开正文" }
    ],
    "related_courses": [
      { "id": "course-uuid", "name": "课程名称" }
    ],
    "source_title": "公开来源名称或空字符串",
    "source_url": "公开 HTTPS 来源或空字符串",
    "correction_url": "公开 HTTPS 纠错入口或空字符串"
  }
}
```

约束：

- `related_courses[].id` 必须使用当前公开课程 UUID；
- `updated_at` 必须表达内容最后一次有效复核时间，不应只使用构建或部署时间；
- 分类必须限制在选课、培养方案、退补选、考试成绩等学习事务范围，不能混入宿舍或校园生活类“指南针”内容；
- `source_url` 和 `correction_url` 只能返回确认可公开的 HTTPS 地址；
- 正文由邵游堃整理，API owner 只需确定数据导入、存储和公开读取方式，不承担 `SYK-06` 的内容编写。

### 4.4 纠错入口的最小选择

`SYK-05` 只要求存在可用的纠错入口，不强制新增小程序内写接口。请由生产 owner 明确选择并记录以下一种方案：

1. 指南详情返回可公开的 `correction_url`，客户端跳转或复制链接；这是最小方案。
2. 明确允许复用现有受控反馈服务，并提供小程序可用的请求契约、类型值、限流和安全错误响应。
3. 新增专用指南纠错接口，并完整说明校验、限流、审核、隐私和错误码。

在生产 owner 明确选择前，客户端不会自行猜测或直接调用写接口。

## 5. 数据、搜索和安全语义

### 5.1 Fuse.js 与完整性

原任务明确要求客户端 Fuse.js 权重。当前客户端历史搜索引擎使用以下主要字段：

- 课程名 `name`；
- 简称 `short_name`；
- 别名 `aliases`；
- 标签 `tags`；
- 教师名 `teachers`；
- 补充文本 `search_text`。

因此，生产索引必须是同一版本下的完整公开快照。客户端会负责权重、匹配词高亮、类型筛选和结果展示；API 不需要返回 Fuse 分数，但不能只提供单页候选数据。

### 5.2 “化学”完整召回证据

为完成 `SYK-03`，API 回交时还需要提供一份不含秘密的生产验收基线：

- 索引版本和生成时间；
- 所有因课程名、简称、别名或标签包含“化学”而应命中的课程 ID 与名称；
- 对应总数；
- 数据 owner 确认该清单来自同一生产快照。

该清单是验收证据，不必成为长期 API 字段。没有生产预期集合时，本地 fixture 通过只能证明算法可用，不能证明“全部相关课程”均被召回。

### 5.3 公共字段白名单

新增接口不得暴露：

- manifest `basePath`、文件相对路径、资源根、本机或服务器路径；
- R2 账号、bucket、secret、管理密码和签名密钥；
- 内部 revision、审核标记、IP/actor hash、User-Agent、联系方式；
- 后台管理元数据、未发布或已隐藏记录。

资源下载仍只接受经过校验的 `https://resources.nkustudy.top` 地址。搜索索引通常不需要包含 `download_url`。

### 5.4 响应和错误

新增 `/api/v1` 接口沿用当前公共响应外形：

```json
{ "code": 0, "data": {} }
```

错误继续使用 HTTP 状态和稳定字符串错误码。至少说明：

- 无效参数：`400`；
- 指南不存在：`404`；
- 限流（如有写入）：`429`；
- 服务端失败：`500`；
- 暂不可用：`503`。

公共错误不得包含服务器路径、provider 原文、堆栈、内部配置或秘密。

## 7. 完成判定

API 部分只有同时满足以下条件才视为完成：

1. 四类搜索索引来自同一完整生产快照，可供客户端 Fuse.js 使用；
2. 课程索引实际提供简称和别名，教师、资料、指南均有独立结果项；
3. 指南列表和详情提供稳定 ID、分类、更新时间、相关课程和明确纠错入口；
4. 正式 API 文档与实际注册路由一致；
5. 生产 owner 提供部署版本、时间和只读验证证据；
6. 新增公共响应通过字段白名单检查，不暴露私有数据；
7. `SYK-03` 的“化学”生产预期集合可被完整召回。

仅完成以下任一项不能视为交接完成：

- 只更新文档但路由仍返回 `404`；
- 只返回课程结果；
- 只对当前分页结果运行 Fuse.js；
- 只实现空的指南页面而没有生产读取契约；
- 用本地参考 mock 代替生产部署证据。
