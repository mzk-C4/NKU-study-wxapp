# 指南针 AI 开发交接

任务状态与五人分工只在 [COLLABORATION_PLAN.md](./COLLABORATION_PLAN.md) 维护；本文件说明联调、后端集成及人工验收。首期仅做基于指南的学习生活问答，最多 10 轮，整段返回。

## API Key 到位前怎样联调

在微信开发者工具的 **develop 环境**控制台执行，然后重新进入指南针 AI 页：

```js
wx.setStorageSync('nkustudy_guide_assistant_mode', 'mock')
```

模拟模式无需登录、联网或模型 Key。页面顶部始终显示“开发演示”；会话存到独立 mock 空间。发送普通问题可演示答案及来源按钮；发送“资料不足”“宿舍”或“冲突”演示业务拒答；`[400]`、`[401]`、`[429]`、`[503]`、`[断网]` 分别演示错误状态。模拟来源按钮仅演示复制学校首页链接，不代表证据原件已验收。模拟 401 不执行真实微信登录，退出该场景可新开话题。

退出模拟模式：

```js
wx.removeStorageSync('nkustudy_guide_assistant_mode')
```

体验版、正式版和无法识别的运行环境忽略该设置，也忽略 `preview` 视觉样例参数。真实模式要求现有微信登录；登录成功后保留问题，用户主动再次发送，不自动重试。

## 沈弋皓开发、邵游堃部署：接入现有网站后端

服务模块为 `integrations/guide-assistant/service.cjs`，不启动服务器、不保存网站数据，也不内置生产指南。当前小程序工作区没有网站后端的有效检出；本次没有修改归档中的网站快照，没有部署生产路由。沈完成该模块在网站后端的代码集成并交付配置项说明，邵在现有服务器执行配置和部署；在现有路由中挂载 `POST /api/v1/guide-assistant/answers`：

1. 使用网站现有 Bearer 校验器实现 `authenticate(req)`，返回服务端认证的数字用户 ID；禁止采用正文中的 user 或 user_id。
2. 用网站的 JSON 读取和响应工具实现 `readJson(req)`、`sendJson(res, status, body)`；请求体限制为 32 KiB，路由只接受 POST。代理和 JSON 解析错误也需转换为受控响应。
3. `loadGuides({profile, signal})` 返回网站当前已发布、已核验且适用于该用户背景的指南。每项提供稳定 `id`、`status: 'published'`、`title`、`sections`、`sources`、`applicable_scope`、`time_status`、`content_type`、`updated_at`。学院 variant 由网站根据已确认的学院/专业关系选取，背景不足时只给校级材料，不拼接其他学院正文。不得把本地五篇草稿直接认作当前生产数据。
4. 来源提供 `id/title/file_url/official_page_url` 等公开字段；文件地址只允许既有资源域的 `/guide-sources/`。引用从检索结果的来源对象回填，模型只返回来源 ID，不能自造 URL。
5. 模型支持服务端 JSON 对话协议时用 `createChatProvider`；其他供应商只需实现同样的 provider 函数。其返回对象和约束见模块的 `SYSTEM_PROMPT`，这也是提示词候选，交沈审核。

接线示例（由网站现有程序提供三个适配函数，不是独立服务器）：

```js
const { createGuideAssistantService, createChatProvider, createAnswerHandler } = require('./guide-assistant/service.cjs')
const provider = createChatProvider({
  endpoint: process.env.AI_CHAT_ENDPOINT,
  model: process.env.AI_MODEL,
  apiKey: process.env.AI_API_KEY
})
const service = createGuideAssistantService({ loadGuides, provider, logger: logSafeEvent })
const answerHandler = createAnswerHandler({ service, authenticate, readJson, sendJson })
// 在网站现有 POST /api/v1/guide-assistant/answers 分支调用 answerHandler(req, res)。
```

`AI_CHAT_ENDPOINT` 是完整 HTTPS JSON 对话地址；适配器期望 `choices[0].message.content` 是约定 JSON 对象的字符串。供应商、模型及配额由后续提供的 Key 确定；当前未选择或测试真实供应商。Key 由邵游堃在网站服务端环境配置；沈提供配置项名称及使用说明。Key不进入小程序、本地会话或日志。

模块默认每个用户每分钟最多 10 次、同一用户同时最多 1 次；模型可重试的失败最多尝试 2 次，两次共用 25 秒总预算，客户端等待 30 秒。索引采用标题与正文词项匹配，取最多 4 篇并携带原文、来源和适用范围；首期不要求向量库。多实例部署前，沈完成共享限流代码接线，邵配置对应的服务端设施；模块内存限流只覆盖单进程。

正式接入前需确认供应商参数、输出格式、真实指南覆盖、请求体上限及代理超时。需要输入/输出内容审核时，复用网站现有审核层，未完成这项核验不能宣称已具备线上审核能力。

## 洪修睿、王绅右：客户端分工与知识交接

洪修睿与王绅右的任务均衡安排，并按个人待办清单逐项核验完成状态。洪负责页面、指南针/搜索入口、来源展示、接口适配及客户端交付；王负责多轮对话、登录恢复、本机会话与账号隔离、异常/手动重试、自动化测试和整体验收。两人先约定页面与控制器接口，各自修改负责模块；同一文件需共同修改时先交接。

- 首页与指南搜索均可进入问答页；搜索词只填入草稿，不自动发送，也不混入上一个话题。
- 页面复用旧版对话、10 轮上限、历史、来源打开器及 Markdown 渲染。只持久化有稳定用户 ID 的账号会话，保留 30 天；模拟会话独立。旧版无账号标记记录保持原样，不自动迁入任何账号。
- 账号变化会取消旧控制器并清空旧页面内容；旧请求不能写入新账号。请求层只清理该请求携带的失效 Token。
- `docs/guide-assistant/knowledge-manifest.json` 登记已有 5 篇本地草稿及原文来源 ID、适用范围、时间限制。生产 ID、当前有效性和原件链接由沈审核、王验收抽查；学生 PDF 暂不作为首期回答依据。

## 王绅右：人工验收表

下列项目当前均为 **NOT_RUN**，本地自动化不能代替真实模型或手机验收。分别记录 iOS、安卓的机型、微信版本、构建版本和结果。

| 场景 | 预期结果 |
|---|---|
| 指南针与搜索入口 | 正确进入；中文和特殊字符带入草稿；不会自动发送 |
| 未登录→主动登录 | 未登录不调用 AI；登录后原问题可手动发送 |
| Token 失效与账号切换 | 清除旧账号画面；旧回答、旧 401 不影响新账号；不自动重发 |
| 正常问答→来源→追问 | 有可核验的原文，适用范围明确；追问保留上下文 |
| 资料不足与来源冲突 | 说明缺失或冲突；可补充条件继续问；不虚构办理入口 |
| 断网、超时、429、503 | 显示受控提示；恢复后可主动重试；失败不增加完成轮次 |
| 重复点击、退出、新话题 | 同一问题只提交一次；旧回答不会串入新话题或卸载后的页面 |
| 第10轮与第11轮 | 第10轮可完成，第11轮引导新开话题 |
| 历史、浅深色、小屏大字体 | 本机历史按账号隔离，来源和输入框可见可操作 |

## 丁宇鑫：AI 辅助材料与演示

`docs/guide-assistant/evaluation-cases.json` 已生成 50 道题：30 道正常问答、10 道拒答/条件不足题、10 道多轮题。每题包含参考要点、来源 ID、审核状态及 `NOT_RUN` 结果。它们是 AI 生成草稿，须沈核验知识依据、刘铠嘉和崔世旭审核答题边界后，再交王用于真实评测；两道冲突题需要受控夹具，不能声称真实文件存在冲突。测试跑通夹具结构不代表这 50 题的模型效果通过。

提示词候选见服务模块 `SYSTEM_PROMPT`。建议页面文案已落到入口、登录恢复、限流及模拟标识；洪审核后统一调整。

使用说明：指南针→问问指南针 AI→输入具体问题→按提示登录→主动发送→查看来源→补充学院或入学年份追问。回答只作办理参考，重要事项核对最新官方文件；新开话题清空当前上下文，会话历史只在本机保存。

演示脚本（约 90 秒）：

1. 10 秒：展示指南针首页及 AI 入口，说明首期回答范围。
2. 20 秒：从指南搜索带入“成绩复核”，展示草稿和主动发送。
3. 20 秒：展示答案、适用范围和真实来源；模拟阶段必须明确说“交互演示”。
4. 20 秒：追问适用年级，再演示资料不足后补充条件。
5. 20 秒：演示网络失败的手动恢复、新开话题及本机会话历史。
