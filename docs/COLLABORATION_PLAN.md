## 协作规则

- `main` 开启分支保护，禁止直接推送；每个 PR 至少一名非作者审核。
- Commit 使用 `feat:`、`fix:`、`docs:`、`refactor:`、`chore:`；单个 PR 只处理一个任务或页面模块。
- 接口变更由沈弋皓审核，最终合并由马兆坤确认，采用 Squash Merge。
- 每项任务均建立 Issue，填写负责人、截止日期、验收条件和关联 PR。
- 完成定义：代码已提交、PR 已审核、接口异常状态覆盖、真机通过、GitHub 与飞书状态同步。
