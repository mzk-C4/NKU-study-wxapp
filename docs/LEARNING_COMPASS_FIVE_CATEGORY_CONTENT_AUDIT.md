## 一、审计结论

第一阶段五个一级分类均已有足够的正式材料来源，可以停止以“继续寻找文件”为主线，转入知识条目和指南正文整理阶段。

当前主要缺口不是原始材料，而是以下加工产物尚未形成：

1. 五类正式知识条目清单；
2. 每条知识的适用范围、时效和原文定位；
3. 可供普通浏览的指南正文、章节和步骤；
4. 多来源引用、冲突提示和查看原文链接；
5. `draft → review → published` 人工审核结果；
6. 可进入普通搜索和AI检索的已发布内容。

南发字〔2026〕82号全文按产品负责人确认视为不可获得且无需继续寻找。它不再属于材料缺口；与其相关的自修 GPA、门数和日期差异只冻结对应字段，不阻塞其他选课内容，也不阻塞五分类整体建设。

培养方案文件虽然齐全，但 UI Content Contract 已明确排除：不作为一级分类、指南正文或第一阶段AI来源，也不列入当前整理任务。

## 三、各分类当前应沉淀的指南内容

### 3.1 选课与修读

已有材料可以形成：

- 2026—2027第一学期2025级选课时间安排；
- 预选、正选和每日放课规则；
- 补退选及跨专业选课；
- 必修课补登；
- 期中退课和W记录；
- 重修选课及课程代码变化；
- 每学期32学分上限；
- 自修的申请对象、流程和当前通知口径。

局部冻结：

- 自修 GPA：学生手册3.7，当前通知3.0；
- 自修门数：学生手册一般1门，当前通知一般2门；
- 自修日期：本地8页PDF写2026年，官网150页PDF写2025年。

处理原则：其他选课内容正常成文；自修差异分别展示来源或暂不提供稳定结论，不再围绕82号扩张检索。

### 3.2 考试与成绩

已有材料可以形成：

- 本科课程考试基本规则；
- 考试冲突如何申请缓考；
- 成绩如何记载、何时录入；
- GPA计算和两级制课程处理；
- 期中退课W记录；
- 对课程成绩有异议时如何申请复核；
- 成绩修改的审批边界；
- 考试违纪与作弊的基本后果和申诉权。

不纳入当前任务：当学期期末考试日程、考场安排以及尚未发布的临时通知。

### 3.3 学籍与毕业

已有材料可以形成：

- 新生入学与每学期注册；
- 学业警示触发条件；
- 休学、续休、复学；
- 退学条件与程序；
- 延期毕业和提前毕业；
- 毕业、结业及相关证书；
- 普通本科生学士学位条件、申请和异议处理。

边界：涉及本人专业具体学分、课程和毕业审核时，引导用户查看教学管理信息系统中的当前培养方案，不使用仓库培养方案作为第一阶段AI来源。

### 3.4 学业拓展

已有材料可以形成：

- 2026年转专业入口与学院差异提示；
- 辅修基本条件和2026年度办理入口；
- 2026年微专业招生入口和项目简介；
- 校内、校际和网络课程学分认定；
- 校际交流结束后的学分认定；
- 国际前沿小学期学分要求；
- 本科实习组织、考核和学生责任。

边界：学院或项目具体条件必须保留各自来源，不能合并成全校统一规则。校际交流项目申请和专业实习具体安排只有在后续确实建设对应指南时再补充，不作为当前材料缺口。

### 3.5 规范与权益

已有材料可以形成：

- 课程作业、论文、实验报告中AI工具的允许、禁止和标注要求；
- 学术不端的类型、受理、调查和复核；
- 考试违纪与作弊的认定层级；
- 处分前的陈述、申辩和救济权；
- 学生处分、退学等决定的申诉期限和流程；
- 学生在学习、评价和申诉方面的基本权利。

边界：不对具体个案作定性或处分预测；学院和课程可以在校级AI规范基础上提出更严格要求。

## 五、首批内容建议

为验证五分类、详情引用和后续AI回答，第一批先各完成一篇真实指南：

1. 选课与修读：`2026—2027第一学期2025级选课时间安排`；
2. 考试与成绩：`对课程成绩有异议，如何申请复核？`；
3. 学籍与毕业：`休学期满后如何申请复学？`；
4. 学业拓展：`2026年微专业如何申请？`；
5. 规范与权益：`本科课程作业中如何规范使用AI工具？`。

每篇至少包含：直接结论、适用范围、章节/步骤、更新时间、来源、原文定位、查看原文、必要的时效或冲突提醒。

这五篇只进入 `draft`，经内容负责人核对后进入 `review`；在正式数据与发布审核完成前不得标为 `published`。
