# NKUStudy 微信小程序 UI 示意

## 页面结构

底部导航采用四项：`首页 / 课程 / 指南 / 我的`。课程详情内部使用 `概览 / 资料 / 评价` 三个页签。

示意图覆盖 12 个核心界面：

1. 首页
2. 课程库
3. 搜索结果
4. 课程详情·概览
5. 课程详情·资料
6. 课程详情·评价
7. 资料领取
8. 选课指南
9. 指南详情
10. 分享资料
11. 写课程评价
12. 我的

## 首页原则

- 第一优先级是全局搜索，支持课程、教师和标签。
- 搜索下方只保留四个高频入口。
- 选课季专题作为时效信息，不使用轮播图。
- 登录用户显示最近浏览和收藏；游客显示大家在看。
- 热门课程卡只显示课程名、关键标签、资料数和评价数。
- 页尾提供学生共建入口，不在首屏堆积统计数字。

## 设计令牌

- 主色：`#4B1F6F`
- 深紫：`#2B123E`
- 金色强调：`#D7A63C`
- 页面背景：`#F6F3F7`
- 内容纸色：`#FFFDF8`
- 主要文字：`#211C24`
- 页面左右边距：`16px / 32rpx`
- 基础圆角：`12–14px`
- 搜索框高度：`44px / 88rpx`
- 主按钮高度：`42–48px`

中文由 HTML 与系统中文字体渲染，不是图片模型生成，因此不会出现乱码。`index.html` 可直接用浏览器打开并继续修改。
